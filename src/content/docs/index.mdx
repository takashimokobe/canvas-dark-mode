## Actions

### Buttons

Buttons are used to trigger actions. Primary buttons use the `accent.action` background color, which references a neutral color in the default theme.

If a tenant sets their primary brand color, the `accent.action` color will be mapped to `brand.primary.600` instead, giving it a colorful accent. Secondary and tertiary buttons are not brandable.

<Specimen slug="button" />

### Segmented Control

A linear group of buttons for selecting one value. Keep to four items or fewer. 

Similar to a Switch, the selected item sits on a washed track - this should be the same color as the Switch's thumb and track.

<Specimen slug="segmented-control" />

### Action Bar

Actions related to a page or task progression. Use the primary action once, then secondary.

## Inputs

Inputs are used to collect user information. Input may or may not have placeholder text inside of them. Regardless, placeholder text within an input should never be used as a label for the input. In order for the input to pass contrast requirements for interactive elements, inputs should have at least 3:1 contrast ratio against the background, which is what the `border.input` color is meant for.
